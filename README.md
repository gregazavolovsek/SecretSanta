# Skrivni Miklavž

Static Secret Santa site. No backend, no database. Each person's assignment is
encrypted (AES-GCM, key derived via HKDF from a 256-bit random token) so only
their own link can reveal it.

```
docs/              the website (publish this folder)
  index.html, style.css, app.js
  data.js          generated by the draw — encrypted, safe to publish
organizer/
  draw.mjs         one-time draw + build script
  links.txt        generated — PRIVATE name → link list (git-ignored)
```

## Run it (once)

Requires Node 18+.

1. Decide where the site will live, e.g. GitHub Pages: `https://<user>.github.io/<repo>/`
2. Run the draw with that URL:

   ```bash
   node organizer/draw.mjs --base-url https://<user>.github.io/<repo>/
   ```

   This writes `docs/data.js` and prints/saves the `name → link` list to `organizer/links.txt`.
   The list never shows who drew whom.
3. Publish `docs/`:
   - **GitHub Pages:** push the repo, then Settings → Pages → Deploy from branch → `main` / `/docs`.
   - **Netlify:** drag the `docs` folder onto app.netlify.com/drop (then re-run step 2 with the Netlify URL if it differs).
4. Send each person only their own link.

The script refuses to run a second time so the draw can't be re-randomized by
accident. `--force` redoes it and invalidates every old link.

## Guarantees

- One single loop over all 16 people: nobody draws themselves, everyone gives and receives exactly one present, no closed pairs.
- `data.js` contains no names in plain text; entries are keyed by a hash of the token, sorted randomly, and padded to the same length, so file order or size reveals nothing.
- A wrong or missing token shows a friendly error. Tokens have 256 bits of randomness and can't be guessed.

**Caveat:** a link *is* the key. Whoever holds `links.txt` could open any link,
so to stay blind yourself: don't open other people's links, and delete
`links.txt` once everyone has theirs. Never commit or publish it.

Exclusions (people who must not draw each other) can be added in
`EXCLUSIONS` at the top of `organizer/draw.mjs`.
